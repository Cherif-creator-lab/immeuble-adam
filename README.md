# إقامة آدم 168 - بوابة تتبع ومراقبة السنديك
# Résidence Adam 168 (Kénitra) - Syndic Audit & Tracking Application

تطبيق ويب عصري وسريع مخصص للملاك المشتركين لتتبع ومراقبة تسيير السنديك (شركة التدبير العقاري COPRO SYNC H T)، والتحقق من مصاريف الميزانية التقديرية (6,000 درهم/شهرياً)، ومتابعة إنجاز قرارات وأشغال الجمع العام الـ 9 بتاريخ 12/08/2026.

## 🚀 المميزات الرئيسية
- 🛠️ **متابعة أشغال وقرارات الجمع العام (9 قرارات)** مع حالة الإنجاز ومقارنة التقديرات بالفواتير المؤداة.
- 📊 **سجل المصاريف والفواتير الحقيقية** المعتمدة مع إمكانية التعديل والإضافة والحذف.
- 🏦 **تتبع الحساب البنكي الحي (التجاري وفا بنك)** ومداخيل كراء شقة السنديك (1,900 درهم/شهرياً).
- 📄 **تحميل تقرير التتبع الشهري الرسمي بصيغة PDF** بضغطة زر واحدة.
- 📱 **واجهة عربية 100% متجاوبة** مع الهواتف الذكية والحواسيب مع الوضع الليلي والمضيء.

## 🛠️ التقنيات المستعملة
- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **jsPDF + jsPDF-AutoTable**

## 💻 التشغيل والتطوير المحلي
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية
npm run build
```
